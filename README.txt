Student Check PWA (ต้นแบบสำหรับ iPhone)

ไฟล์ที่ต้องนำขึ้นโฮสต์ไว้ในโฟลเดอร์เดียวกัน:
- index.html
- manifest.json
- sw.js
- icon.svg

การเข้าสู่ระบบเริ่มต้น:
ชื่อผู้ใช้: teacher
รหัสผ่าน: 1234

ก่อนใช้จริง ให้แก้ TEACHER_USERNAME และ TEACHER_PASSWORD ใน index.html
ข้อควรทราบ: การล็อกอินนี้เป็นเพียงการล็อกหน้าจอเบื้องต้น เพราะข้อมูลบัญชีอยู่ในโค้ดที่เบราว์เซอร์ดาวน์โหลดได้ ห้ามใช้กับข้อมูลลับหรือข้อมูลนักเรียนที่มีความอ่อนไหวโดยคาดหวังความปลอดภัยสูง

ข้อมูลถูกเก็บใน localStorage ของเบราว์เซอร์ ไม่ซิงก์ไปเครื่องอื่น การล้างข้อมูลเว็บไซต์อาจทำให้ข้อมูลหาย ควรส่งออกข้อมูลสำรองเป็นระยะ
